# -Jogo-Termo-em-FPGA-com-Interface-de-Teclado-PS-2-e-Display-LCD-16-2
Implementação em hardware do jogo Termo (Wordle) descrita em VHDL para FPGA (Xilinx Spartan-3A/3AN) a 50 MHz, integrando receptor serial PS/2 (Scan Code Set 2), Máquina de Estados Finitos (FSM) com avaliador combinacional de duas passagens e controlador de display LCD 16x2.
